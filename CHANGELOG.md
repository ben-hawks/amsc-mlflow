# Changelog

## 0.1 (2026-10-02)

First version of the `amsc-mlflow` skill:
- connectivity check;
- benchmark-results and eval-bundle logging;
- model registration from runs or manifest-checked checkpoints, with aliases;
- the `amsc_mlflow` helper (token file and expiry, multipart uploads, rank-0 runs, tags);
- HPC job snippet;
- training template;
- references;
- end-to-end tests against a local MLflow server.
